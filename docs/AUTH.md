# 账号、权限与行程额度

普通用户可注册、登录、修改密码，历史记录只展示自己的行程。新账号默认累计创建 3 个行程，不按月重置；解析成功并保存时计数，解析失败不计数，编辑、重新规划、分享和导出已有行程不重复计数。复制别人分享的行程属于新建。管理员不限量，可在 `/admin` 调整每人的总额度、启停账号、更改角色、重置密码。最后一个启用的管理员不能被停用或降级。

历史页每条行程提供“删除”，经确认后移入服务器回收站，刷新或换设备仍保持删除状态。回收站支持恢复，保留原 ID、地点、路线、日期和分享状态；已分享的行程在回收站期间不可访问，恢复后原链接继续有效。普通用户只能操作自己的行程，管理员可管理旧的无所属行程。删除与恢复均不返还或再次消耗累计创建额度。回收站暂不提供永久清空，不会自动清理行程或关联的视频文件；视频仍按原有效期处理。旧页面不能通过自动保存重新激活已删除的行程。

## 首次管理员

本机直接访问 `/admin/setup`，自行设置用户名和密码。只允许没有管理员时初始化；公开注册始终创建普通用户，不会因为是第一个注册者就获得管理员权限。

服务器部署请使用 HTTPS，并在服务器环境中临时设置至少 24 字符的随机 `ADMIN_SETUP_TOKEN`，重启服务后访问 `/admin/setup`，输入该令牌创建管理员。创建完成后移除令牌并重启。也可以通过 SSH 隧道直接访问服务器的本机服务完成初始化。不要将令牌、密码放入网址、前端或版本库。

Express 仅信任回环代理；Nginx 应连接 `127.0.0.1`，传递原始 `Host`、`X-Forwarded-Proto $scheme` 与 `X-Forwarded-For`。账号服务拒绝公网 HTTP 和跨来源修改；HTTPS 会话使用 Secure、HttpOnly、SameSite=Lax Cookie，服务器只保存令牌摘要。管理员会话 12 小时，普通用户 7 天；停用账号、更改角色、重置密码会撤销其旧会话。密码使用随机盐和 scrypt 保存，不提供密码明文查看。

## 服务配置与存储

管理员可在 `/admin` 的“服务设置”中修改模型、高德、视频和注册开关；普通用户无法读写配置接口。密钥只显示已配置状态，不返回原文。配置仍写入 `SETTINGS_FILE`（默认 `data/local-settings.json`），优先于 `.env`，不是保存在浏览器。数据库、端口及初始化令牌仍由服务器环境配置。

用户、额度、会话与行程共用 `SQLITE_DB_PATH`（默认 `data/map-tour.sqlite`）。新行程保存和额度扣除在同一 SQLite 事务内执行，同时提交也不会超过额度。旧行程新增可空的所属用户列，原始内容和分享链接保留；历史未归属行程可由管理员查看和管理，普通用户不能覆盖。新草稿仅作者与管理员可读，主动分享后才允许其他人通过链接查看。

浏览器的地图偏好、配乐选择及本机导出视频仍属于设备本地数据；它们不会随账号同步。后台视频任务按账号隔离；旧的匿名视频任务仍使用原设备 Cookie，不自动迁移到新账号。

部署前备份数据库及服务配置，保留 `.env`、SQLite、视频目录、音乐与配置文件。不要用空测试数据覆盖已有数据库。上线需要独立执行部署与备份，见 [服务器部署](DEPLOYMENT.md)。
