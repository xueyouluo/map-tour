# 湖蓝与草木地图配色

路线地图使用暖白底色、湖蓝水域与草木绿自然区域，保留深蓝工作台边框；卫星图使用原始影像和深色控件。配色目标在 `src/shared/mapTheme.ts`，道路、水域及区域面需在高德编辑器发布后生效，JSAPI 不会直接读取这份色表。

| 元素 | 颜色 | 用法 |
| --- | --- | --- |
| 陆地 | `#f3f1eb` | 暖白底色，让自然绿与湖蓝更清楚 |
| 河流、湖泊 | `#a4cbe0` | 清透湖蓝，保留水陆边界 |
| 主路 | `#ffffff` | 白色道路，边线 `#c7d3df`，二级道路边线 `#cdd8e3` |
| 小路 | `#f8fafc` | 更弱的支路，边线 `#d6dfe8` |
| 景区区域 | `#d8e4c5` | 柔和浅绿；山地植被随底图分类着色，不改变高程或地形阴影 |
| 绿地、公园 | `#c6dbb5` | 低饱和草木绿；当前底图不单独区分森林和公园 |
| 商业区域 | `#e3d9ed` | 淡紫，区别于自然地物 |
| 文教、文化 | `#eee2c7` | 奶油米色，适合校园和博物馆区域 |
| 医疗区域 | `#f0dfdc` | 柔和浅粉 |
| 建筑顶面 | `#d3d7da` | 未分类楼块使用中性灰 |
| 建筑侧面 | `#b6bec5` | 比顶面稍暗，保持立体层次 |
| 行程路线 | `#2563eb` 等 | 浅底用清晰的蓝/紫/青等日序色；卫星图切回原有浅色线条 |

浅底图的标题、地点标签和控件独立适配；名称使用白底深字，路线加白色描边，移除原有深色暗角。

## 尚需分类数据的设计色

完整色板在 `journeyLandUsePalette`；可视化设计稿为 `/designs/landuse-palette.html`，其中抽象街区仅展示配色，不是实际地理覆盖物。

| 类别 | 设计色 | 当前状态 |
| --- | --- | --- |
| 森林 | `#b9d0a4` | 当前随绿地统一使用绿色，独立深浅需要森林分类 |
| 工业园 | `#e5d8ae` | 等待可靠的工业园边界与用途数据 |
| 仓储 | `#d4d7d9` | 等待分类边界 |
| 写字楼、办公 | `#d6deef` | 商业底图不等于写字楼，独立着色等待分类数据 |
| 住宅 | `#ece1d2` | 等待住宅街区或建筑用途数据 |

高德当前区域样式项包括陆地、绿地、停车场、教育体育、公共设施、交通枢纽、景区、文化、医疗卫生、运动场所、商业场所、地铁设施，不提供工业/办公/住宅独立样式项。不能把公共设施全部当作工业，或把未知楼块全部当作住宅；现有建筑保留中性灰。后续若加入用途数据，需保留真实分类及边界来源，再使用对应色值。

## 接入

1. 使用地图 Key 所属账号打开高德自定义地图编辑器，创建或编辑独立样式。设置上表颜色，保留原始几何和道路层级；无关 POI 标注由应用关闭，行程地点由应用绘制。
2. 发布样式后，将 ID 配到本地 `.env` 的 `AMAP_MAP_STYLE_ID`，支持纯 ID 或 `amap://styles/ID`。
3. 首次配置时重启 API 并刷新地图。编辑已有样式无需更换 ID；发布后需刷新验证地图服务的样式缓存已更新。

本地样式名为“Map Tour · 蓝色旅程”，ID 仅配置在本机 `.env`。控制台楼块颜色编辑会触发专业版提示，建筑顶面和侧面改用 JSAPI 参数；未购买升级服务。未配置或 ID 格式错误时使用高德“远山黛”亮色预设。

四站样例 `/s/demo-eastlake-four` 从本地武汉三日游的第三天派生，保留原有 POI 与三段路线几何，原行程未修改。

卫星地图与视频场景仍使用原始卫星影像。这份矢量底图配色不改变影像中的山水建筑。

参考：[高德自定义地图](https://lbs.amap.com/api/javascript-api-v2/guide/map/map-style/)。
