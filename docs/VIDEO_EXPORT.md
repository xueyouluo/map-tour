# 旅程视频

行程页面的“生成旅程视频”把完整行程制作成连续地图视频。每天的足迹保留在同一张地图上，小车或步行人物沿路线前进，镜头自动跟随、缩放。输出为 1080×1920、30 fps、H.264 MP4，有配乐时包含 AAC 音轨。

## 用户流程

1. 导入行程，等待地点匹配、路线规划结束，或打开已有行程。
2. 打开视频窗口，选择自动时长或 30 / 60 / 90 秒。不足以容纳路线的时长会禁用。
3. 配乐可以选择内置曲库、自己的音乐或无配乐。内置曲库有五种风格各 A/B 两版，共 10 首，提供开头 20 秒试听；选择会在本机记住，切换工作区或开始生成会停止试听。上传限制为 25 MB、5 秒至 20 分钟，音乐不能短于视频；服务端检查实际音频内容。
4. 点击“预览我的旅程”。支持 H.264 视频编码以及所需 AAC 编码的浏览器，先由后台准备地图、地形和配乐，随后在页面内播放真正的 3D 场景，可播放、暂停和拖动进度。
5. 点击“导出 MP4 视频”，通过 WebCodecs 在本机逐帧渲染、编码和封装，不需要把视频上传给服务器。完成后可播放、下载。
6. 浏览器不支持所需编码时，直接提交后台队列。本机渲染/编码出错、长时间无进展或页面切入后台时，自动使用同一份行程快照、时长和配乐创建后台视频。也可以主动选择“直接使用后台制作”或“改用后台制作”。主动取消本机导出不会提交后台任务。

本机导出时需要保持页面打开；关闭标签页、退出浏览器或系统直接终止页面，不能保证能完成后台交接。导出期间会提供离页提醒。后台制作可关闭窗口或刷新，稍后回来查看。

地点未匹配时不会编造坐标。缺少规划数据的衔接保留为示意线，提交前与成片中都有提示。只在页面选择某一天，不会裁掉视频中的其他天。镜头按路线长短分配时间，当前没有自动识别音乐节拍。

## 实现与运行环境

- `src/browserVideo.ts`：编码能力检测，Mediabunny + WebCodecs 的 H.264/AAC 编码与 MP4 封装，逐帧时间戳、输出格式检查、本地 IndexedDB 存储。编码模块按需加载，不进入页面首屏主包。
- `src/VideoExport.tsx`：配置、素材准备、实时场景、浏览器导出、取消、自动/手动后台交接、两类历史记录。
- `tools/video-preview/browser/film.js`：浏览器和后台复用的 Three.js 场景；`seekAsync` 等待当前镜头高清纹理就绪后输出确定帧。嵌入页面时降低纹理驻留量，可见补片不会被移除。
- `server/videoJobs.ts`：单 worker 持久队列，同时支持 `scene` 素材准备和完整后台视频；素材准备调用 CLI 的 `--assets-only`，不进行逐帧视频渲染。后台视频继续由 Chrome + FFmpeg 制作。
- 服务端仍需要地图素材采集运行时：Chrome/Chromium、`ffmpeg`、`ffprobe`、`curl`，以及 `AMAP_JSAPI_KEY`、`AMAP_SECURITY_JS_CODE`。浏览器优先减少服务器视频渲染负担，并没有取消地图、地形和音频准备。
- 浏览器导出要求 HTTPS 或 localhost 安全上下文，运行时检测实际编码格式。移动设备的显存、内存和速度存在差异，支持检测通过仍可能在执行中转后台。
- 卫星图源于高德 JSAPI，真实高程来自公开 Mapzen Terrarium；地图素材通过同源的私有路由提供，不向客户端暴露地图安全码。没有 AI 视频生成、Suno API 或额外音乐生成服务。

内置曲库由用户提供的 Suno MP3 导入，归一化至约 -16 LUFS，真峰值目标 -2 dBTP，保留完整音轨并另制 20 秒试听。缺少曲库时保留原版 120 BPM 程序合成器乐。内置与上传音乐均使用连续片段，不改变速度，带淡入淡出；两种导出方式复用相同音频准备。浏览器 AAC 编码可能包含几十毫秒的编码延迟。

运行 `npm run music:import -- --source /绝对路径/合集目录` 可导入本次编号 01–10 的五组 A/B 文件。导入使用两遍响度归一化、解码校验、源文件和成品 SHA-256、不可变音频文件名及原子目录清单更新；不会修改源文件。曲库位于 `assets/music/`（可用 `VIDEO_MUSIC_DIR` 指向其他目录），完整音轨不通过通用静态文件服务公开，只提供曲库元信息和试听端点。首次接入需重启 API。曲库文件独立于下载来源文件夹。

曲目为“晴天出发”“湖边散步”“城市明信片”“山野小路”“江南来信”，每种两个版本；A/B 标签对应合集文件顺序，未按主观喜好淘汰版本。生成时的授权记录应随来源另存，导入工具不会替用户推定授权。

## 保存、恢复与隔离

- 浏览器成片保存在当前网站的 IndexedDB，保留最近 3 条，可刷新恢复。空间不足时仍能下载，但会提示立即保存。浏览器清理网站数据、隐私模式退出等可能清除成片，因此建议下载。
- 浏览器存储与后台 Cookie 是两种独立的恢复方式；本机成片不会自动上传到服务端。删除本机记录会释放其 Blob。
- 后台任务保存在 `VIDEO_EXPORT_DIR/jobs.sqlite`，以独立 UUID 目录保存不可变行程快照，不改原行程数据库。
- 素材准备可以跨页面关闭和刷新继续；尚未导出的预览可从任务列表恢复。相同快照、参数、音乐和场景代码版本可复用未过期素材。
- 后台成片、场景素材和上传音乐保留 7 天，活动任务受保护。全局最多 20 个未完成任务，每个浏览器最多 2 个，串行执行。
- 后台取消、重试、删除、进程租约、重启恢复与资产锁继续有效；未知或活跃的其他任务锁不会被接管。
- 任务、场景、上传音乐和媒体路由绑定 HttpOnly、SameSite Cookie；其他浏览器即使知道 UUID 也无法读取。场景路由仅开放播放器、计划、地形、影像和配乐的明确文件白名单，不提供输入快照、日志、manifest 或任意文件路径。
- 场景页面只能由同源页面嵌入。视频播放支持 HTTP Range，私有响应使用 `Cache-Control: private, no-store`。

`data/video-exports/`、`outputs/`、`assets/music/` 已忽略，不要提交任务数据库、音乐、缓存和生成文件。本地部署或迁移时需要单独保留曲库文件与 `catalog.json`。

## API

所有路径位于 `/api/video`，任务/素材使用当前浏览器 Cookie。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/capabilities` | 地图准备与后台制作运行时是否可用 |
| GET | `/music` | 内置曲库元信息，不含文件路径或来源文件信息 |
| GET | `/music/:id/preview` | 内置配乐的 20 秒 MP3 试听，支持 Range |
| POST | `/scenes` | `{ itinerary, options }`，准备浏览器场景 |
| POST | `/jobs` | `{ itinerary, options }`，直接后台制作 |
| GET | `/jobs?itineraryId=ID` | 当前浏览器的行程任务 |
| GET | `/jobs/:id` | 状态、进度和完成后的 URL |
| GET | `/jobs/:id/scene/*` | 已完成私有场景的白名单文件 |
| POST | `/jobs/:id/fallback` | 从原快照和选项创建完整后台视频 |
| POST | `/jobs/:id/cancel` | 取消排队/运行任务 |
| POST | `/jobs/:id/retry` | 保持任务种类，新建重试 |
| DELETE | `/jobs/:id` | 删除终态任务及文件 |
| POST | `/uploads` | 上传 `music` 音频文件 |
| GET | `/jobs/:id/video` | 播放后台 MP4 |
| GET | `/jobs/:id/download` | 下载后台 MP4 |
| GET | `/jobs/:id/cover` | 后台成片封面 |

任务状态为 `queued`、`running`、`cancelling`、`completed`、`failed`、`cancelled`。`kind: scene` 的完成表示素材经过检查且已准备好，不代表视频已生成；仅返回 `sceneUrl`。完整视频只有子进程正常退出且解码、播放验证通过，才发布视频 URL。

内置配乐选项为 `{ music: 'library', trackId: '曲库返回的ID' }`。任务在创建时验证文件校验和与时长，选择及曲名会保留到浏览器导出和后台兜底。`upbeat`、`upload`、`none` 旧选项继续兼容。

## 验证与上线边界

运行 `npm run test`、`npm run build`。验收需要真实生成浏览器视频，验证默认/上传音乐/无配乐、取消、刷新恢复、编码故障和不支持设备的后台兜底、素材白名单与跨浏览器隔离，并对下载 MP4 完整解码、检查关键帧。页面检查覆盖桌面、手机竖屏/横屏和空行程导入。

生产代理应允许 25 MB 上传（例如 `client_max_body_size 32m`），运行账户需要浏览器、字体、编码工具、数据目录和足够磁盘。当前只支持单 worker，多个 API 进程不能共用同一任务目录。服务器部署与运行配置见 [服务器部署](DEPLOYMENT.md)；未对真实 iPhone/Android 设备做验收。

## 旅行电影工作台

当前行程页默认进入电影工作台：深蓝灰背景、冰蓝选中态、暖橙导出按钮。左侧保留可编辑的逐日行程，底部章节条与日程筛选、真实预览跳转联动，点击已匹配地点也可跳到相应镜头；地图作为独立工作区保留。已导出视频可以使用播放器时间轴浏览，章节条继续控制当前行程的日期筛选。

视频配置、实时预览、任务进度和下载现在直接嵌入页面，不再需要先打开弹窗。顶栏“导出视频”在尚无预览时准备当前行程预览，预览就绪后开始本机导出，已有成片时下载视频。本机编码期间暂时禁用工作区与章节切换。地图仍保持挂载和有效容器尺寸，切换回来时重新适配视野。

手机竖屏保持中央影片、底部章节与可展开行程，配置区可以滚动查看；横屏采用双栏。空行程始终显示导入表单。地图素材和原始路线不会因主题切换而变色或重写，原有按天分色仍用于辨认各天足迹。
