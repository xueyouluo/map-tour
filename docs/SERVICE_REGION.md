# 当前服务范围：中国大陆

当前范围是固定业务规则 `CN_MAINLAND`，没有管理员或前端开关可关闭。港澳台及海外目的地尚未接入。导入页显示相同的覆盖说明。

## 校验位置

- 文字和截图解析共用模型，同时要求 `serviceRegion` 和地点 `countryCode`。结构化结果在清理前后都校验；不能靠删除不支持的地点把混合行程变成国内行程。无法确认地区时拒绝并要求补充省市。
- `ItineraryStore.save` 在开启写事务、增加累计行程数量前校验；直接提交 JSON、另存和编辑也受限制。已有历史不做删除或迁移，仍可查看、删除和恢复。
- `inferJourneyTransport` 在调用模型前校验。
- 视频场景、后台制作、重试和转后台在 `VideoJobs.create` 校验；重启后读取的旧队列也在执行 runner 前校验。旧场景素材经 `sceneFile` 校验，不能作为新浏览器制作的入口。已有成片下载保持可用。
- 高德代理在转发前校验 `origin/destination/location/locations/waypoints` 坐标和明确的非大陆行政区代码。它不是任意地图关键词的语义分类器；产品范围由结构化地点及最终坐标共同校验。

## 规则及资源

行政区正向白名单、明确的非 CN 国家/地区信息、坐标多边形和路线所有提供的顶点都会检查。不能只用覆盖中国的大矩形；矩形内的首尔、河内、海参崴等坐标同样拒绝。无坐标的初次解析必须有可确认的大陆省市上下文，不能默认空值代表中国。

国内飞机和轮渡允许两处大陆端点之间的窄直线示意走廊跨水域；这不会允许任意绕到境外的路径。地图数据为近似边界，边缘点可能需要核对和调整。见 [数据来源与更新](../server/geo/README.md)。本规则是产品覆盖限制，不是导航或测绘服务。

校验无外部请求、不额外调用模型或高德。边界只在服务端加载，不进入前端包。已持久化的视频快照不可变，校验成功后按任务 ID 在当前进程缓存，避免每个素材重复扫描路线；重启清空，删除或过期清理时移除。

服务拒绝返回 HTTP 422 和明确说明。流式解析已发出响应头时返回 NDJSON `type: error`，不发成功 `result`。失败的导入不保存、不扣额度、不创建视频任务；自动化 API 回归使用本地模拟模型，不消耗真实服务额度。

运行：`npm run test`、`npm run build`。回归覆盖文本/截图普通及流式解析、直接保存绕过、编辑、交通接口、场景及后台任务、旧队列与重试、地图代理、混合行程、伪造行政区以及推荐吃住。
